02 / STAR CASES

학습 사례

실제 대화에서 확인된 질문과 설명을 중심으로 기록했습니다.

PYTHON BASICS 학습일 미기록

enumerate()와 2차원 리스트 이해하기

학생별 점수 리스트를 반복 처리하는 코드에서 반복 번호와 각 항목의 역할을 이해한 사례입니다.

S

Situation · 상황

Python 기초를 학습하며 학생별 점수가 담긴 2차원 리스트를 반복문으로 처리하는 코드를 살펴봤다.

T

Task · 과제

enumerate(scores, 1)의 숫자 1이 의미하는 것과 반복할 때 i, row에 들어가는 값을 이해하고자 했다.

A

Action · 행동

내가 한 일: enumerate()의 동작 방식과 반복마다 i의 값이 어떻게 변하는지 질문하고, 설명을 바탕으로 이해한 내용을 확인했다.

AI의 도움: 반복 번호와 실제 리스트 인덱스의 차이를 설명하고, 각 반복에서 번호와 점수 리스트가 어떻게 대응하는지 예시로 보여 줬다.

R

Result · 결과

enumerate()의 시작 번호 1과 리스트의 실제 인덱스는 구분해야 하며, 반복할 때 i에는 번호가, row에는 해당 점수 리스트가 들어간다는 점을 확인했다.

기록 범위: 실제로 사용하며 이해했지만 해당 관련 문서는 업로드하지 않음.
